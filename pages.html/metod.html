📖 Инструкция

Как пользоваться Vibe Check

О приложении

Vibe Check — приложение для отслеживания настроения, дневника и команд.

🏠 Главная страница

  • Выбираем настроение (1–5)
  • Выбираем тег или пишем свою заметку
  • Нажимаем «Сохранить»
  • Запись сохраняется в дневник автоматически

📔 Дневник

  • Отображаются все сохранённые записи
  • Можно открыть запись по дате
  • Можно искать записи по дате
  • Можно фильтровать по настроению (смайликам)

🏷️ Теги

  • Добавляются при создании записи
  • Помогают группировать записи
  • Можно анализировать частые причины настроения

📊 Аналитика

  • Показывает график настроения
  • Показывает среднее настроение
  • Можно выбрать период просмотра

📅 Календарь

  • Каждый день отмечен цветом настроения
  • Нажатие на день открывает запись
  • Можно быстро просматривать историю

👥 Команды

  • Можно создать команду
  • Можно добавить участников
  • Есть общий чат команды
  • Показывается общая статистика настроения

➕ Добавление участников

  • Нажимаем «Добавить участника»
  • Получаем код приглашения
  • Отправляем код другому пользователю
  • Он вводит код и присоединяется к команде

Профиль

  • Профиль — изменение данных пользователя
  • Жалобы - можете написать что не понравилось
  • Советы - можете написать, что стоит добавить для улучшения Vibe-Chek
  • Уведомления — включение/выключение напоминаний
  • Отзывы - можете написать ваше мнение, как вам наше приложение.
