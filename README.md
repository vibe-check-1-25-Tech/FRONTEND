# 💜 Vibe Check — Frontend

## 📌 О проекте

**Vibe Check** — это веб-приложение для отслеживания эмоционального состояния пользователя, анализа настроения и улучшения эмоционального благополучия.

Приложение помогает фиксировать настроение, вести дневник эмоций, анализировать изменения состояния через графики и получать персонализированную статистику.

Проект создан для развития эмоциональной осознанности, самоконтроля и поддержки психоэмоционального состояния пользователя.

---

## ✨ Основные возможности

### 💜 Check-in (настроение)
- Быстрая оценка настроения
- Выбор эмоции через эмодзи
- Добавление заметок
- Ежедневная фиксация состояния
- Прикрепление фото

---

### 📘 Дневник
- Запись мыслей и эмоций
- История записей
- Теги для категорий
- Отслеживание изменений настроения

---

### 📊 Аналитика
- Графики изменения настроения
- Статистика эмоций
- Анализ периодов: 3 / 7 / 14 / 30 дней
- Диаграммы распределения эмоций
- Среднее настроение пользователя

---

### 📅 Календарь
- История настроения по дням
- Навигация по датам

---

### 🏷 Теги
- Категоризация записей
- Быстрый выбор тегов
- Возможность добавления новых тегов

---

### 👥 Команда
- Отслеживание настроения команды
- Общая эмоциональная аналитика


---

### 👤 Профиль
- Редактирование данных
- Настройки аккаунта
- Аватар
- Жалобы
- Отзывы
- Предложения
---

### 📤 Экспорт
- Выгрузка данных пользователя
- История записей
