# 💜 Vibe Check

## О проекте

**Vibe Check** — это веб-приложение для отслеживания эмоционального состояния пользователя, анализа настроения и улучшения эмоционального благополучия.

Приложение помогает пользователю фиксировать настроение, вести дневник эмоций, анализировать изменения состояния через графики и получать персонализированную статистику.

Проект создан с целью улучшения эмоционального самоконтроля, повышения осознанности и поддержки психоэмоционального состояния пользователя.

---

## Основные возможности

### 💜 Check-in (Чек-ин настроения)

* Быстрая оценка настроения
* Выбор эмоционального состояния через эмодзи
* Добавление заметок к самочувствию
* Ежедневная фиксация состояния

### 📘 Дневник

* Запись мыслей и эмоций
* История записей
* Добавление тегов
* Отслеживание эмоциональных изменений

### 📊 Аналитика

* Графики изменения настроения
* Статистика эмоций
* Анализ за:

  * 3 дня
  * 7 дней
  * 14 дней
  * 30 дней
* Круговые диаграммы распределения эмоций
* Среднее настроение пользователя

### 📅 Календарь

* Просмотр истории эмоциональных записей
* Отображение настроения по дням
* Навигация по датам

### 🏷 Теги

* Категоризация записей
* Быстрый поиск по эмоциям
* Сортировка записей

### 👥 Команда

* Отслеживание настроения внутри команды
* Совместный эмоциональный мониторинг
* Аналитика общего состояния команды

### 🆘 Поддержка

* Жалобы
* Отзывы
* Предложения по улучшению
* Обратная связь

### 👤 Профиль

* Редактирование данных пользователя
* Изменение пароля
* Смена аватара
* Управление настройками


### 📤 Экспорт

* Сохранение истории настроения
* Выгрузка данных пользователя

## Установка проекта

1. Клонировать репозиторий:

```bash
git clone <repository-url>
```

2. Перейти в папку проекта:

```bash
cd vibe-check
```

3. Запустить проект через Live Server или открыть `index.html`.
